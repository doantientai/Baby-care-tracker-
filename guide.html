1Installer sur le téléphone

Pas de store : l’appli est une page web qui s’ajoute à l’écran d’accueil comme une vraie appli.

iPhone (Safari)

  1. Ouvrez l’appli dans Safari.
  2. Touchez le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisissez Sur l’écran d’accueil, puis Ajouter.

Android (Chrome)

  1. Ouvrez l’appli dans Chrome.
  2. Touchez le menu ⋮ en haut à droite.
  3. Choisissez Ajouter à l’écran d’accueil (ou Installer l’application).
💡 L’icône 🍼 apparaît sur l’écran d’accueil. Ouvrez toujours l’appli depuis cette icône.

2Premiers réglages

Touchez ⚙️ Réglages en bas à droite.

  1. Langue : Français, English ou Tiếng Việt.
  2. Bébé : son prénom et sa date de naissance.La date de naissance sert aux repères selon l’âge : fièvre, nombre de couches par jour.
  3. Intervenants : les personnes qui s’occupent de bébé (par ex. Maman, Papa, Mamie). Chaque entrée indique qui l’a faite.
  4. Lieu & unités : votre ville, pour la météo et le conseil « quoi mettre à bébé ».

3Noter au quotidien

Tout se fait depuis l’écran 🏠 Accueil, d’une main.

🤱 Une tétée

  1. Touchez Début G ou Début D.Le ✦ indique le sein à proposer : celui qui n’a pas commencé la dernière fois.
  2. Pour passer à l’autre sein : ⇄ Changer. Pour un rot ou une pause : ⏸ Pause.
  3. À la fin : ■ Arrêter, vérifiez, puis Enregistrer. Le temps de chaque côté est enregistré.
▶ La vidéo (35 s, sans son)

🧷 Une couche

  1. Dans Saisie rapide, touchez 🧷 Couche.
  2. Choisissez Pipi, Caca ou Les deux, puis la quantité et la couleur.Un message explique la couleur choisie. Blanche, rouge ou noire après les premiers jours : appelez le médecin.
  3. Touchez Enregistrer en bas.
▶ La vidéo (27 s, sans son)

💊 La vitamine D

Chaque matin, un rappel apparaît sur l’accueil jusqu’à ce que la dose soit notée. Touchez Noter, c’est tout. L’heure du rappel se change dans Réglages → Rappels.

⏱ Noté en retard, ou une erreur ?

Dans chaque fiche, l’heure se règle en un geste : -5m -15m -30m -1h… Pour corriger ou supprimer une entrée, ouvrez 📜 Journal et touchez-la.

4Connecter le deuxième téléphone

Facultatif, environ 5 minutes, une seule fois. Les deux parents voient alors le même carnet. Les données passent par un Google Sheet qui vous appartient.

💻 C’est plus simple sur un ordinateur, avec le compte Google d’un des parents.

Côté Google (une seule fois)

  1. Ouvrez sheets.google.com et créez une feuille vierge. Donnez-lui un nom, par ex. « Carnet bébé ».
  2. Dans le menu : Extensions → Apps Script.
  3. Effacez le code affiché, collez ce script (tout le texte), puis touchez 💾 Enregistrer.
  4. Déployer → Nouveau déploiement. Cliquez sur ⚙️ à côté de « Sélectionner le type » → Application Web.
  5. Réglez Exécuter en tant que : Moi et Qui a accès : Tout le monde, puis Déployer.
  6. Google demande une autorisation : Autoriser l’accès → votre compte → Paramètres avancés → Accéder à … (non sécurisé) → Autoriser.Cet avertissement est normal : c’est votre propre script, que Google n’a pas « vérifié ». Il ne peut lire que cette feuille.
  7. Copiez l’URL de l’application Web (elle finit par /exec).
Les libellés de Google peuvent varier légèrement selon la langue et la version.

Côté appli

  1. Sur le premier téléphone : Réglages → Synchronisation (Google Sheet), collez l’URL, puis ⟳ Synchroniser. Vous devez voir ✓ Synchronisé.
  2. Touchez Copier le lien et envoyez-le au deuxième téléphone (SMS, WhatsApp…).
  3. Sur le deuxième téléphone, ouvrez ce lien : il est connecté. Ajoutez-le à l’écran d’accueil (étape 1).
▶ La vidéo (23 s, sans son)
🔑 Ce lien donne accès à votre carnet : ne le partagez qu’avec des personnes de confiance.

5Sur une liseuse Kindle

Un écran doux pour la table de nuit : grands boutons, noir et blanc, sans animation.

  1. Sur le premier téléphone, Réglages → Synchronisation → Copier le lien. Le lien est court, pour pouvoir le taper à la main.
  2. Sur le Kindle : menu ⋮ → Navigateur web, puis tapez ce lien.
  3. Dans l’appli : Réglages → Mode liseuse → Activé. Ajoutez la page aux favoris du navigateur.
  4. Si l’heure affichée est fausse (les Kindle sont souvent réglés sur UTC) : Réglages → Fuseau horaire → UTC+1 en hiver, UTC+2 en été, pour la France.

6Écran de chevet

Un ancien téléphone posé à l’horizontale, toujours allumé : il affiche depuis combien de temps bébé a mangé, et quel sein proposer. Rien à toucher, il se met à jour tout seul.

  1. Connectez ce téléphone au carnet : Copier le lien écran sur le premier téléphone, puis ouvrez le lien sur l’ancien. Ou, dans l’appli : Réglages → Écran permanent → Ouvrir l’écran.
  2. Ajoutez la page aux favoris, tournez le téléphone à l’horizontale et touchez ⛶ pour le plein écran.
  3. Branchez-le, et empêchez la mise en veille.iPhone : Réglages → Luminosité et affichage → Verrouillage automatique → Jamais. Android : Paramètres → Affichage → Mise en veille de l’écran → le plus long.

7En cas de souci

« Échec de la synchronisation » s’affiche en rouge
Vérifiez que le téléphone a internet, puis touchez Réessayer. Si ça continue : vérifiez que l’URL finit bien par /exec. Rien n’est perdu, les entrées restent sur le téléphone.
Pas de réseau à la maternité
Notez normalement. Un bandeau « Hors ligne » indique combien d’entrées attendent ; elles partent toutes seules au retour du réseau.
Les entrées de l’autre téléphone n’apparaissent pas
Les deux téléphones doivent avoir la même URL dans Réglages → Synchronisation. Touchez ⟳ Synchroniser pour forcer la mise à jour.
L’heure est fausse sur le Kindle
Réglages → Fuseau horaire → UTC+1 (hiver) ou UTC+2 (été).
« Nouvelle version disponible »
Touchez Mettre à jour : l’appli se recharge, vos données restent.
Changer de téléphone, ou garder une copie
Avec la synchronisation, il suffit d’ouvrir le lien sur le nouveau téléphone. Sinon : Réglages → Sauvegarde & partage → ⬇ Exporter sauvegarde, puis ⬆ Importer sauvegarde sur l’autre.
⚕️ Les repères de l’appli (fièvre, couleur des selles, nombre de couches) sont des informations générales, pas un avis médical. En cas de doute, appelez votre médecin, votre sage-femme ou le 15.
